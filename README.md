# FreeForYoung 🆓⚡

Автообновляемая Happ-совместимая подписка, которая собирает публичные бесплатные VLESS / VMess / Trojan / Shadowsocks / Hysteria2 узлы, удаляет дубли, проверяет TCP-доступность и публикует лучшие доступные узлы.

> ⚠️ Это агрегатор чужих публичных узлов, а не собственная VPN-сеть. Публичные бесплатные серверы могут быть нестабильными и потенциально недоверенными. Не отправляйте через них пароли, банковские данные и другой чувствительный трафик.

## Happ

После запуска GitHub Actions файл подписки находится в `output/subscription.txt`.

Raw URL после загрузки репозитория:

`https://raw.githubusercontent.com/ВАШ_USERNAME/FreeForYoung/main/output/subscription.txt`

## Что делает проект

1. Загружает несколько публичных источников.
2. Извлекает URI конфигураций.
3. Удаляет дубликаты.
4. Проверяет TCP endpoint.
5. Сортирует рабочие узлы по задержке.
6. Публикует ограниченный список лучших найденных узлов.
7. GitHub Actions обновляет подписку каждые 6 часов.

Источники указаны в `sources.txt` и легко заменяются.

## Локальный запуск

```bash
python scripts/build_subscription.py
```

## GitHub Actions

Откройте Actions → `Update FreeForYoung` → Run workflow. После этого обновлённая подписка будет лежать в `output/subscription.txt`.
